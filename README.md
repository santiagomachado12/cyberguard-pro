# CyberGuard Pro

Advanced Network Monitoring & Security Operations Platform

## Stack
- **Backend**: ASP.NET Core 8, C#, Entity Framework Core, PostgreSQL
- **Frontend**: React 18, TypeScript, Vite
- **Monitoring Worker**: Python 3.11+, FastAPI
- **Infrastructure**: Docker, Docker Compose, Nginx
- **CI/CD**: GitHub Actions

## Quick Start (Codespaces)
cd backend && dotnet restore && dotnet build
cd frontend && npm install && npm run dev
cd monitoring && python -m venv .venv && source .venv/bin/activate && pip install -r requirements.txt
